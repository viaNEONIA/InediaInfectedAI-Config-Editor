# 言語ファイル仕様 v1

UTF-8のJSONです。BOM付きにも対応します。最大2MB、説明は最大5000件です。

```json
{
  "schemaVersion": 1,
  "locale": "ja-JP",
  "name": "日本語カスタム",
  "entries": {
    "Zombies.SpeedLimitInCalmMode": {
      "label": "平常時の速度上限",
      "description": "平常時の移動速度の上限です。",
      "unit": "速度値",
      "source": "https://github.com/ysaroka/InediaInfectedAI/wiki/Description#zombiesspeedlimitincalmmode"
    }
  }
}
```

## 項目

| 項目 | 必須 | 内容 |
|---|---|---|
| schemaVersion | はい | 整数1 |
| locale | はい | 言語識別子。例 ja-JP、en-US |
| name | はい | 画面に表示する言語名 |
| entries | はい | 設定パスから説明への対応表 |
| label | 各説明に必須 | 表示名 |
| description | 各説明に必須 | 説明本文。改行可能 |
| unit | 各説明に必須 | 単位や値の種類。不要なら空文字 |
| source | 任意 | httpsの参照URL。省略するとリンクなし |
| review | 任意 | 確認状況を記録する文字列。表示動作には影響しない |

`updatedAt` 等の追加メタデータは読込可能ですが、エディターからの出力では維持しません。

## パス

- `Zombies.SmellsHandlerIsActive` と `Players.SmellsHandlerIsActive` は別項目です。
- `Vehicles.Noise.*.RpmMaxMeters` の `*` は任意の車両クラス名1区間に一致します。
- `Zombies.ThrowingProjectiles.*.Parameters.TargetHealthDamage` は任意の投擲物の当該項目を指します。
- 完全一致がワイルドカードより優先します。ワイルドカード同士では固定区間の多い方を優先し、同数ならファイル内の定義順です。
- 独自のクラス名にドットを含む場合、その位置のワイルドカードは内部の1キーに一致します。区切りを含む任意キーの完全パス指定は推奨しません。
- 項目の下の `all` や対象名ごとに同じ説明を重複表示せず、親の設定に説明を表示します。

## 読込の扱い

読み込んだ項目は1件単位で内蔵説明を置き換えます。部分変更でもlabel・description・unitの3つを指定してください。空文字を指定すると、その表示内容を消せます。元の英語キーは消えません。

不正な形式やhttps以外の参照URLはファイル全体を拒否し、現在の言語を維持します。説明はHTMLとして実行せずテキスト表示します。

言語ファイルとMOD設定JSONは別形式です。言語ファイルは「言語ファイルを開く」で読み込んでください。
